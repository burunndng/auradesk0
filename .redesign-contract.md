# AuraDesk Redesign — Shared Design Contract

**Codename:** "Obsidian Sanctuary — Lapis & Gilt"
**Direction:** A spatial, visionOS-inspired desktop OS on cool obsidian-indigo glass, warmed by a single precious **gilt (gold)** accent reserved for the scarab brand and focal interactions. Preserves the Egyptian-mystical identity (scarab, cartouche frames, hieroglyph hairlines, constellation depth) but renders it in a fresh COOL palette — deliberately distinct from the prior warm-black/gold SerK3t theme AND from BLISS's neutral zinc/Inter DAW look.

## Fonts (Google Fonts import)
- **Display:** `'Marcellus'` (elegant Roman/Egyptian-friendly serif) — headings, brand, window titles
- **Body:** `'Manrope'` (modern geometric sans) — UI text
- **Mono:** `'IBM Plex Mono'` — eyebrows, code, clocks

Import line (index.css agent owns):
```
@import url('https://fonts.googleapis.com/css2?family=Marcellus&family=Manrope:wght@300;400;500;600;700&family=IBM+Plex+Mono:wght@300;400;500;600&display=swap');
```

## Design motifs to apply across components

1. **Spatial glass:** every panel/window uses `backdrop-filter: blur(18px)`, 1px lapis border, layered shadows, inset top highlight `inset 0 1px 0 rgba(255,255,255,0.06)`.
2. **Cartouche focus:** active/focused windows and key CTAs get the `.cartouche` treatment (thin gilt inset border + soft gilt glow). Inactive get lapis hairline only.
3. **Hieroglyph hairlines:** use `.hairline` gradient dividers between sections.
4. **Gilt is scarce & precious:** scarab logo, active window title text, primary brand buttons, focus rings on brand elements ONLY. Everything else structural/interactive uses lapis.
5. **Constellation depth:** background is deep obsidian-indigo with a faint starfield + radial lapis nebula glow — cool night-sky, not warm parchment.
6. **Larger radii, softer depth:** use new radius scale; windows float with `--shadow-lg`.
7. **SVG icons only** (Lucide-style strokes), never emoji glyphs as icons.

## Hard constraints for ALL agents

- **DO NOT change** component logic, props, state, store interactions, event handlers, or export names/signatures.

- Match existing code style; do not add comments unless the file already uses them heavily.
- Ensure the file is **syntactically valid TS/TSX** — `npx tsc --noEmit` must pass.
- Prefer Tailwind arbitrary values like `bg-[var(--bg-window)]`, `border-[var(--border-default)]`, `text-[var(--gilt)]`, or inline styles referencing the vars.
